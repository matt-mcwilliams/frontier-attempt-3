## Future: Sign in with ChatGPT

Sign in with ChatGPT is reserved as a future integration option. This repository does not currently implement sign-in, request credentials, or make AI requests.

When implementation is requested, review the current [official OpenAI documentation for open-source and locally hosted apps](https://developers.openai.com/siwc/token-sharing-open-source). It describes user sign-in and optional permission to use an eligible ChatGPT plan. Paid or remotely hosted integrations have a separate onboarding path described there; making this repository public does not itself register an integration or enable authentication.
