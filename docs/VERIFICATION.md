# Verification

## Automated scope

Tests exercise actual application code. Test model replies are injected only in backend tests; production has no mock provider mode.

- SQLite restart continuity for objective, source, and conversation.
- Instructional decisions, prerequisite return points, exact quotation validation, attachment-backed image evidence, and evidence-required exercise completion.
- Native-frame crop coordinates, letterboxing, portrait dimensions, rotation, and full-frame capture.
- PDF.js extraction from an original generated PDF, retaining page markers.
- DOI parsing and private import-target rejection.
- SSE fragmentation, Unicode, CRLF, partial structured prose, late usage failure, and explicit completion.
- Outbound Responses protocol: OAuth bearer, image input, structured JSON, explicit history, `store: false`, `stream: true`, and omission of unsupported parameters.
- API authentication, loopback bootstrap, cross-origin rejection, daily guard, and rollback after model failure.
- OIDC signature, audience, issuer, nonce, expiration, and returning identity. Dynamic registration uses stable host ID, fresh PKCE, exact loopback callback, and rejects invalid/replayed state before code exchange.
- Production UI over isolated HTTPS: rendering, real API calls, PDF upload/extraction, source persistence, themes, history, and drafts.
- Real WebRTC negotiation between two browser contexts with a synthetic camera. Video reaches the desktop; selection freezes, rotation works, source-resolution crops attach, and attachments alone make no tutor request.
- Phone layout and recovery from missing pairing credentials.

Live Crossref/OpenAlex verification has been run for both seeded papers. This verifies metadata, not full-text access.

## Real-account and physical-device checks still required

This environment has no app-authorized ChatGPT grant or physical phone. No live tutoring completion, mathematical handwriting diagnosis, account-specific structured output support, real token-refresh/revocation round trip, or mobile certificate/permission behavior has been claimed as tested.

1. Continue with ChatGPT, approve plan use, and confirm the model catalog loads. Acknowledge the first-use plan message. No API key should be requested.
2. Import your permitted Gibbons and Hedeker PDF, check that it matches the selected bibliographic record, and begin a journey. Verify that the tutor distinguishes source claims from explanations.
3. Ask about conditioning/local independence, take a prerequisite detour, and inspect the saved return point.
4. Request a derivation without its solution. Configure trusted LAN HTTPS, pair a physical phone, and submit a selected handwritten attempt with a deliberate error.
5. Check symbol legibility, orientation, and mathematical feedback. Submit an illegible crop and confirm the tutor requests clarification rather than guessing.
6. Correct the error. Inspect separate evidence for misconception and improvement; return to the paper. Check cited pages against the original source.
7. Repeat with a hint and confirm assisted evidence. Complete an implementation; later attempt delayed recall without notes and inspect that evidence separately.
8. Reload and restart. Check lesson/source continuity and phone reconnection after sleep or a Wi-Fi interruption. Expired QR links must fail; ordinary image upload must remain available.
9. Stop a response and interrupt the network. Confirm drafts persist and partial output becomes no learning evidence. Check plan-limit and unsupported-model recovery.
10. Add another account/workspace, reauthorize saved registrations, and check that identities, credentials, and permissions remain separate. Verify sign-out revocation or disconnect manually in ChatGPT settings when revocation is unconfirmed.

## First-version limits

Personal local hosting; no public multi-user deployment, built-in TURN relay, or automatic certificate installation. Tutoring quality needs evaluation with real learner work; this is not a completed efficacy study. Retrieval is lexical; there is no OCR, general HTML import, autonomous research agent, lecture timestamp discovery, arbitrary executable diagram support, or code execution. No record deletion/restoration UI or encrypted credential vault; secure full-directory backups preserve all artifacts.
